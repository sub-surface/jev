# experiments/

One folder per experiment, named `eNNN_short_name/`. Each folder contains:

- **`README.md`.** Write the question, the prediction and the setup *before* running. Add the results afterwards, including the negative ones.
- **`run.py`.** The script must be self-contained. It imports `calib/`, fixes its seeds, and writes every number it reports to `results_*.json`.
- **Figures** generated by `run.py`, never drawn by hand.

Defaults:
- Run on the laptop (CPU or RTX 2060).
- Any cloud run needs a written justification in the README *before* it is run. See `../RESEARCH.md` §6 for the cloud policy.
