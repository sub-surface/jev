# figures/

All figures are generated by `python experiments/make_figures.py` from the saved `experiments/*/results_*.json` files. Each comes as a 200-dpi PNG and a vector PDF. No figure contains hand-typed numbers.

| Figure | What it shows |
|---|---|
| `fig01_ledger` | E001: bits = UNC − DSC + MCB for 8 binary sources × a compute ladder |
| `fig02_jumps` | E001: cumulative code length; inference over structure vs memory |
| `fig03_dynamics` | E001: calibration at a shift; escalation gates; diagonal adversaries |
| `fig04_golay` | E002 + E003: Golay/PSL(2,23); symmetry earns bits only through the right learner |
| `fig05_arithmetic_ladder` | E002B + E004: GL(1) → GL(2); the primes carry the information; Hecke weight 12 rediscovered |
| `fig06_amortisation` | E000: amortising shortest-path search into one pass |
