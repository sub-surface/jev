# local global obstruction

A k-local observer of the Golay code gets **exactly 0 bits** about any coordinate for k <= 6, because the dual distance is 8. At k = 7 it gets 1 bit, and only on octads. Information that is invisible locally and present globally is the information-theoretic form of a local-to-global obstruction, which is what cohomology measures. Pseudorandomness is the same obstruction at unbounded order for bounded observers. **The k-local information profile is a general, cheap diagnostic of where a source's structure lives.**

**Source:** E005 (exact enumeration); MacWilliams & Sloane (dual distance and orthogonal arrays); Abramsky & Brandenburger 2011 (sheaf-theoretic contextuality).

**Test / open:** Can the profile predict which architectures can learn a source? Conjecture: a learner whose receptive field or feature order is below the obstruction order extracts nothing (CTW, MLP on Golay).
