# the number 24

Where 24 recurs: Delta = eta^24 (so tau(n) has weight 12); the Leech lattice is 24-dimensional; the moonshine module is a c = 24 field theory; the Golay code has length 24 = |P^1(F_23)|, with M24 acting on it. Also 1^2 + 2^2 + ... + 24^2 = 70^2, the only nontrivial case of a square square-pyramidal number (Watson). That Lorentzian vector (0, 1, ..., 24 | 70) builds the Leech lattice inside II_{25,1}. The prime 23 also links Delta mod 23 (via the weight-1 form eta(z)eta(23z) and x^3 - x - 1) to the quadratic-residue code mod 23 that E002 uses. Whether that last link is more than shared arithmetic is *speculative*.

**Source:** Conway & Sloane, SPLAG ch. 26-27; Watson 1918; Serre on Delta mod 23.
