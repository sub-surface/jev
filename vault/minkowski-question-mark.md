# minkowski question mark

Minkowski's ?(x) maps the continued fraction x = [0; a1, a2, ...] to the binary number written as alternating runs of lengths a1, a2, .... It is the change of coordinates between the Stern-Brocot tree (the modular group PSL(2,Z) acting on the rationals) and the dyadic tree. E001's 'minkowski ?(u)' source is exactly this map applied to uniform reals: learnable run-length structure, which CTW extracts.

**Source:** Minkowski 1904; Salem 1943; E001.
