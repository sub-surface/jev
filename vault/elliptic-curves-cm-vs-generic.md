# elliptic curves cm vs generic

On the ledger, CM elliptic curves are GL(1) in disguise. For y^2 = x^3 - x, MDL finds the supersingular set (p = 3 mod 4) and costs 0 bits. The sign of a_p costs 1 bit to every residue observer but only **0.002 bits** to an observer with the Gaussian-integer data of p = a^2 + b^2, i.e. the Hecke character. Non-CM curves cost 1.000 bit/symbol to every observer tested (Sato-Tate): genuinely GL(2) information. Bonus: MDL found 11a's mod-5 structure (rational 5-torsion) from bits alone.

**Source:** E006; Deuring (CM theory); Sato-Tate (Barnet-Lamb, Geraghty, Harris & Taylor 2011).

**Test / open:** Which *learned* observers capture non-CM information? It requires modularity-level knowledge, e.g. Hecke eigenvalue relations across primes, not per-prime features. Murmurations: averaged over curve families, rank does leak into a_p.
