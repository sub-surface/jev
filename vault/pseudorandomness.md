# pseudorandomness

A sequence is pseudorandom *relative to an observer class* if no member of the class predicts it better than chance. In E001 the LCG top-bit source costs about 1.00 bit per symbol for every observer up to CTW-12, despite having a description under 100 bits. Randomness is observer-relative. The matching notion of 'honest' is calibration relative to a class (outcome indistinguishability).

**Source:** Yao 1982; Dwork et al. 2021 (outcome indistinguishability); E001.
