# library of babel as coordinates

Every predictor P is a coordinate system on the Library of Babel. Arithmetic coding places each string in a subinterval of [0,1) of length P(string), and the string's address is its code. Calibration means the map's scale is honest; resolution means useful regions get large intervals. The universal map (Solomonoff, or Levin's ordering) is maximally coherent but uncomputable, and every computable map has diagonal blind spots. Organising the library means learning a better prior.

**Source:** Synthesis of [[code-length-is-log-loss]] and [[universal-prediction]].

**Test / open:** Measure how well a learned prior locates *useful* sequences (program outputs, natural data) relative to random ones, as a code-length gap.
