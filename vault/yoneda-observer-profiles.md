# yoneda observer profiles

Yoneda: an object is determined by the maps into it. Read for us: **a source is determined, up to what an observer class can distinguish, by its profile of code lengths across that class.** The E001 ledger matrix (sources x observers) is a truncated Yoneda embedding, and outcome indistinguishability is equality of those restricted profiles. 'Making the model an algebraic topologist' means equipping it with observers that detect global obstructions, such as k-local profiles, symmetry orbits and parity checks.

**Source:** Yoneda lemma (e.g. Riehl, *Category Theory in Context*, ch. 2); Dwork et al. 2021 (outcome indistinguishability); E001, E005.

**Test / open:** Cluster sources by their observer profile. Do clusters coincide with generator families (the Yoneda prediction)? Which observers separate families that look identical to the rest?
