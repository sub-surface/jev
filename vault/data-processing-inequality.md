# data processing inequality

No post-processing of a predictor's output can increase I(Y; f). Shannon information is never created by a map, only kept or lost. Isotonic recalibration keeps it exactly when the map is injective on the forecasts that occur. So 'inference is a morphism that does not conserve information' is right in Shannon's sense in one direction only: it cannot create information.

**Source:** Cover & Thomas, ch. 2.
