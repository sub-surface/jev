# vault: atomic notes

Rules, to stop the notes drifting the way the old docs did:

1. **One note, one claim.** Each note is a few sentences long, with its source and its links. If a note needs a second claim, make a second note.
2. **Every note has a `status`:**
   - **established:** textbook or peer-reviewed, or reproduced here.
   - **conjecture:** a precise claim with a planned test.
   - **speculative:** an intuition we keep, with what would make it testable.
   - **refuted:** wrong; kept, with the evidence.
3. **Mark uncertain citations `[verify]`** until someone has read the paper.
4. **Experiments cite notes, and notes cite experiments.** A note changes status only on evidence.
5. **Questions live in `QUESTIONS.md`.** It is the one registry, each question has an ID, and nothing is deleted. Answered questions get marked as answered.

Start with [`MAP.md`](MAP.md) and [`QUESTIONS.md`](QUESTIONS.md). Plain markdown with `[[links]]`, so it opens in Obsidian.
